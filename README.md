# 🌍 Projeto Viagem  

Projeto desenvolvido em dupla para a disciplina **Aplicações para Internet**, com objetivo de praticar e aplicar conceitos de desenvolvimento web.  
O site simula uma **página de viagens**, trazendo uma interface simples, intuitiva e responsiva, com informações e imagens que remetem a destinos turísticos.  

Este trabalho foi inspirado em uma empresa de turismo localizada na cidade de Caaporã - PB, interior da Paraíba, servindo como base para a criação do layout e conteúdo.  

🔗 Acesse o site: [Clique aqui para visualizar](https://layssamartins.github.io/ProjetoViagem/)
